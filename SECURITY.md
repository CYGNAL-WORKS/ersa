# Security

Report a vulnerability privately: select **Report a vulnerability** on the repository's Security tab. Don't open a public issue for it.

**What counts.** Ersa is an agentic development harness that runs coding agents with your credentials on your projects. Anything that lets a project, a session, a backend, or another process on the machine act beyond what you allowed is in scope. So is anything that exposes a session's content or your credentials to someone else.

**Fixes.** Fixes will reference the report, and will credit you if desired.
