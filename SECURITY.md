# Security

Report a vulnerability privately: select **Report a vulnerability** on the repository's Security tab. Don't open a public issue for it. The owner answers each report personally.

**What counts.** Ersa runs coding agents on your machine with your own credentials and your own projects. Anything that lets a project, a session, a backend, or another process on the machine act beyond what you allowed is in scope. So is anything that exposes a session's content or your credentials to someone else.

**Fixes.** A fix lands on `main` as a pull request that names the report, and its description credits you if you want that.
