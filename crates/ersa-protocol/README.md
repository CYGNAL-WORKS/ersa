# ersa-protocol

The Rust types for the two protocols between the Interface and Core: the Core API and the agent event stream. JSON Schema is the source of truth for both; these types implement the schemas, and the Interface's TypeScript types are generated from the same schemas. The `events` module implements `protocol/schema/agent-events.schema.json`, and `tests/schema_conformance.rs` checks every event type against it. The Core API types are still a placeholder. The crate depends on serde and serde_json only: no Core internals, no async runtime, no Tauri, and nothing platform-specific. The `schema-validation` feature adds a validator for tests in any crate that wants to check the events it produces.
