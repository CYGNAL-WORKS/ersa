# Contributing

Ersa is built by its owner with coding agents; `CLAUDE.md` says how.

**Code.** Ersa doesn't take outside pull requests. A pull request from a fork is closed with thanks, and the project's own merge review never runs on one (ADR 0023).

**Bug reports.** Open an issue with what you did, what you expected, what happened, your platform, and the backend CLI and its version. An issue is a report, not a ticket: only the owner's text defines work for an agent session.

**Ideas.** An issue is fine for those too.

**Security.** Don't report a vulnerability in an issue; `SECURITY.md` says how.
