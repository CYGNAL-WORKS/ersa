# Contributing

Ersa is a product built with and for agentic development.

**Code.** Ersa doesn't take outside pull requests. A pull request from a fork will be closed with thanks.

**Bug reports.** Open an issue with what you did, what you expected, what happened, your platform, and the backend CLI and its version. No SLA or promises for bug reports.

**Ideas.** An issue is fine for those too.

**Security.** Please report security vulnerabilities as described in `SECURITY.md`.
