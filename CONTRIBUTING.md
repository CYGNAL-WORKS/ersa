# Contributing

Ersa is built by its owner with coding agents. The briefs in `docs/briefs/` are the source of truth, tickets are GitHub issues cut from them, and agent sessions build the tickets under the rules in `CLAUDE.md`. Read that file first if you want to understand how anything here came to be.

**Code.** Ersa doesn't take outside pull requests right now. A pull request from a fork is closed with thanks, and the project's own merge review never runs on one. This file says so when that changes.

**Bug reports.** Open an issue with what you did, what you expected, what happened, your platform, and the backend CLI and its version (for example, Claude Code 2.1.316). An issue is a report, not a ticket: only the owner's text defines work for an agent session.

**Ideas.** An issue is fine for those too. Ersa is pre-alpha, so most ideas wait until the first milestone runs.

**Security.** Don't report a vulnerability in an issue; `SECURITY.md` says how.
