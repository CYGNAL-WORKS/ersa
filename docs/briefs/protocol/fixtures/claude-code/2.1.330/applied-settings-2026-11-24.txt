The control request `get_settings` (`{"subtype":"get_settings"}`):
- It answers success before any message, with `effective`, `sources`, `served_settings_state` and `applied`.

- `applied.effort` is the effort a session will run with: launched with `--effort xhigh` it read `xhigh`, and after `apply_flag_settings` with `effortLevel: high` it read `high`.
- `applied.model` follows the model: launched with `--model haiku` it read `claude-haiku-5-5`, and after each `set_model` the CLI answered it read the id that answer gave.
- With no effort named, `applied.effort` was `medium` for every listed model: after `set_model` to `default`, `opus`, `sonnet` and `haiku`, and at launch with `--model sonnet` and with `--model claude-fable-5-2[1m]`.
