# 0008: UI framework

- Status: proposed
- Date: 2026-10-31
- Related briefs: ARCH-CORE, LAY-SHELL

## Context

The interface runs in Tauri's webview and is written in TypeScript. It needs rich animation, a component gallery with screenshot tests, a markdown and code renderer, virtualised transcripts, and an ecosystem the implementing model knows well. The decision is needed before the first interface ticket.

## Options considered

1. **React 19 + TypeScript**, animation via Motion (formerly Framer Motion), gallery via Storybook. Largest ecosystem; most reliably generated by coding models; heavier runtime.
2. **Svelte 5**: excellent built-in transitions and a small runtime; less ecosystem for complex transcript rendering and fewer trained examples.
3. **Solid**: fast and small; the smallest ecosystem of the three.

## Decision

Pending. Recommendation: option 1, because implementation quality from the implementing model and ecosystem depth matter more than runtime size for a desktop app, and the design system is ours either way.
