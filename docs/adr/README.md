# Architecture Decision Records

One decision per file. Status is one of `proposed`, `accepted`, `superseded by NNNN`, `rejected`. A record is never edited after acceptance except to change its status; a change of mind is a new record that supersedes the old one.

Record a decision when it would be costly to reverse, or when a future reader could plausibly have chosen differently and needs to know why we did not. Anyone, including an implementing session, may add a `proposed` record; only a planning pass accepts one.
