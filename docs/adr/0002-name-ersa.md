# 0002: Name the product Ersa

- Status: accepted
- Date: 2026-10-31

## Context

The predecessor's name was an internal joke tied to a former employer and had to go. Requirements for the new name: soft-sounding, one or two syllables, a mythological or science-fiction undertone without pretension, and no collision with an existing software product. Dozens of candidates were checked against web search, crates.io, npm, PyPI, GitHub, and common domains.

## Options considered

Rejected for collisions: Loom (Atlassian), Weft (weftapp.studio), Kiln (Kiln AI), Jig, Lathe, Kore (Kore.ai), Mneme, Ananke, Muninn, Ariadne, Clotho (Klotho), Skeld (Among Us), Elara, Umbriel (Umbrel). Rejected for tone: Briareus, Hecaton, Aegaeon (obscure, reads as pretentious), Skuld (harsh). Shortlisted and clear: Embla, Anthe, Narvi, Sigyn, Ersa.

## Decision

**Ersa**, the Greek goddess of dew and a moon of Jupiter named in 2019. Pronounced ER-sa. Free on crates.io and PyPI; npm holds an abandoned empty placeholder; the GitHub user `ersa` exists, so the organisation will be `ersa-app` or similar. The only name collision is Ersa GmbH, a German soldering-equipment maker in an unrelated industry.

## Consequences

Identifiers use `ersa`. Prose uses Ersa. The dew metaphor (work that appears overnight while nobody is watching) is available for onboarding copy and the design brief but is not required anywhere.
